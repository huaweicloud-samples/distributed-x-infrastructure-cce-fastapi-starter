## 组件说明

### CCE（云容器引擎）

CCE 提供托管 Kubernetes 集群，用于运行 FastAPI 容器应用。本方案中：

1. **CCE 集群** — 指定集群规格、VPC、子网
2. **节点池** — 指定节点规格、数量、存储
3. **ELB 负载均衡器** — 独立创建并配置监听器、后端服务器组
4. **Kubernetes 部署清单** — Deployment + Service YAML

CCE 提供细粒度的控制能力，可以灵活配置集群和节点参数。

### RDS for PostgreSQL

RDS 提供稳定的托管 PostgreSQL 服务，备份策略已内置。支持手动规格变更以适应不同负载场景。

### CSMS（凭据管理）

CSMS 提供凭据存储与检索功能，用于安全管理数据库密码。凭据轮转需手动触发。

### SWR（镜像仓库）

SWR 用于存储容器镜像，应用构建后推送到 SWR，CCE 节点从 SWR 拉取镜像部署。

### ELB（弹性负载均衡）

ELB 对外暴露应用，将公网流量转发到 CCE 节点上的 FastAPI 容器。配置健康检查路径 `/health`。

### IAM 委托

IAM 委托授权 CCE 集群访问 SWR 和 RDS 服务。
